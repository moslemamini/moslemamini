# Moslem Amini

I work on applied machine learning systems, with a current focus on retrieval, LLM-based applications and deep learning.

My recent projects include a fine-tuned embedding and retrieval pipeline for question answering, Persian semantic search, computer-vision models, recurrent time-series models, and data-engineering workflows with Airflow.

## Selected projects

- **FinQuery** — semantic QA system using a fine-tuned BGE embedding model, FAISS, Kafka and Docker
- **Persian Semantic Search** — inverted index, TF-IDF ranking and Word2Vec query expansion
- **Facial Emotion Recognition** — FER-2013 experiments with classical baselines and a CNN
- **NLP Language Modeling** — unigram/bigram and RNN/LSTM/GRU/BiLSTM comparisons
- **Financial Time-Series Forecasting** — recurrent models for stock and Bitcoin sequences
- **Airflow Supermarket Analytics** — CSV → SQLite → scheduled analytical tasks and charts

I am gradually turning my coursework and research prototypes into reproducible repositories with clear assumptions, evaluation and setup instructions.
